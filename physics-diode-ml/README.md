# Semiconductor Diode I–V Characteristics with Machine Learning

A Class XII Physics investigatory project analysing a measured forward-bias current–voltage (I–V) curve of a 1N4004 diode and comparing two regression models.

## Research question
How well can regression models predict measured diode current from voltage, and how do their predictions differ across a held-out voltage interval?

## Dataset
The measurements come from the public [diode I–V measurements dataset](https://github.com/blueberrye-io/diode-iv-measurements/). This project uses `data/1n4004_forward.csv`, with measured voltage (`v_meas`) and current (`i_meas`). The first unsettled/invalid row is removed during cleaning. The dataset is credited to its original authors and is released under CC BY 4.0.

## Methods
1. Load and inspect the published measurement data.
2. Remove missing/non-finite values and non-forward-bias rows.
3. Plot the measured I–V characteristic, including a logarithmic current axis to make the low-current region visible.
4. Hold out a middle interval of voltage values and train on the lower and upper regions.
5. Compare linear regression with a random-forest regressor using MAE, RMSE, and R².
6. Plot predictions and residuals.

## Important limitation
This is a small, single-diode dataset. The held-out interval tests interpolation across a deliberately withheld region; it does not establish that a model generalises to other diode types, temperatures, circuits, or measurement equipment. Results must be reported from the actual run, not assumed in advance.
